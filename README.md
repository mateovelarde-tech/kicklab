# 🥋 KickLab - Plataforma Web de Taekwondo

KickLab es una aplicación web deportiva diseñada para competidores y practicantes de Taekwondo. Permite gestionar planificaciones semanales, rutinas de entrenamiento, seguimiento del peso objetivo, cuenta atrás para torneos y registro detallado de sensaciones y técnicas post-entrenamiento.

---

## 📁 Estructura del Proyecto

```text
├── index.html           # Página principal: resumen de la semana, próximos torneos y registro rápido
├── entrenamientos.html  # Biblioteca de rutinas clasificadas y calendario interactivo
├── avances.html         # Control de avances, modelo de información y tabla de sesiones
├── perfil.html          # Datos deportivos, configuración del atleta y preferencias de privacidad
├── style.css            # Hoja de estilos centralizada con variables, layout y diseño responsivo
├── img/                 # Recursos gráficos y fotografías de alta resolución
│   ├── hero-inicio.jpg
│   ├── hero-entrenamientos.jpg
│   ├── hero-avances.jpg
│   └── hero-perfil.jpg
└── tipografia/          # Fuentes locales (opcional) y enlaces a Google Fonts (Outfit)
```

---

## 🚀 Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura limpia y accesible con etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<form>`).
- **CSS3 Moderno**:
  - CSS Grid & Flexbox para layouts complejos y adaptables.
  - Variables CSS (`:root`) con paleta de colores extraída directamente de Figma.
  - Diseño totalmente responsivo (móvil, tablet y escritorio).
- **Tipografía**: [Outfit](https://fonts.google.com/specimen/Outfit) de Google Fonts.
